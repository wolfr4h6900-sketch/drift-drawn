DRIFT&DRAWN — WHITE + CYAN EDITION

This version has:
- White professional theme
- Cyan-blue accent color
- Original DRIFT&DRAWN logo included
- Size selector REMOVED from product pages
- Home page
- Shop page
- Search
- Categories and filters
- Product pages
- Cart
- Checkout front-end
- Mobile responsive layout

QUICK SETUP
1. Extract the ZIP.
2. Open the gearvault_website folder in VS Code.
3. Open index.html.
4. Recommended: install VS Code "Live Server" and click "Go Live".

EDIT PRODUCTS
Open js/products.js and change name, price, category, description and image URL.

EDIT DESIGN
Open css/style.css.
The main accent is:
--cyan:#08bfe8

EDIT CONTENT
Open index.html / shop.html / checkout.html.

PAYMENTS
The checkout is a front-end demo. Real UPI/card payments and real order management need a payment gateway and backend.

Use your own product artwork/photos or content you have permission to sell.
